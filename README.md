## About

I’m Sweta, a software developer focused on backend engineering and full-stack product development. I enjoy designing APIs, connecting services, and turning ideas into usable applications. My projects range from Spring Boot microservices to AI-assisted learning and storytelling products.

- Building: **HealOps + MediFlow**, a healthcare workflow demo with service monitoring and bounded recovery actions.
- Exploring: service architecture, API security, event-driven integrations, and containerized development.
- Open to: collaboration on practical backend and full-stack projects.

## Focus areas

- **Backend:** REST APIs, authentication, persistence, and service boundaries.
- **Frontend:** React interfaces, dashboards, responsive layouts, and data visualization.
- **Microservices & distributed systems:** gateway routing, gRPC, Kafka, service health, and event streams.
- **Databases:** MongoDB and H2 in project implementations; PostgreSQL drivers also appear in Java service modules.
- **Cloud & DevOps learning:** Docker/Compose, Nginx, AWS CDK, LocalStack, and deployment workflows.
- **Engineering practice:** API documentation, integration testing, observability signals, and fault/recovery flows.

<summary>Project notes</summary>

- **HealOps:** scheduled health probes → incident and policy evaluation → allowlisted Docker action → follow-up health verification. The README explains the local demo scope and optional services.

- **StoryVerse:** separate React/Vite frontend and Express/MongoDB backend; reader, creator, and publishing workflows with AI generation and Cloudinary media support.
- **Data Analytics Dashboard:** React/Vite dashboard backed by Express and MongoDB, with protected routes and charting. API includes auth and filtered data endpoints.
- **Admin–Employee Dashboard:** React app with role-specific views and task assignment/status workflows; uses React Context and local storage utilities.
